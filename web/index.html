The gap

Changelogs exist. Nobody reads them.

Stripe renames a field. A vendor kills an endpoint. You find out when prod 500s at 2am.

Watch

Every spec, every hour

A cron pulls each vendor's OpenAPI spec and keeps the last one.

Diff

What actually broke

Removed endpoints, dropped params, new required fields. New endpoints are noted, not flagged.

Find

Your calls, by file

It searches your repo for the calls that just went away and opens one issue with the list.

CI

Red builds, watched

One issue per failing workflow on every repo. Closed when the run goes green.

Fix

A PR with the fix

Claude Code reads the failing log, fixes the root cause, re-runs the step and opens the PR.

Honest

Says when it can't

Outages, missing secrets and Mac-only builds get a note on the issue, not a guess.

Why not a status page

A knock on your door

A status page tells everyone the same thing. Tripwire tells you what broke in your code. A weather report, versus someone at your door with an umbrella.
